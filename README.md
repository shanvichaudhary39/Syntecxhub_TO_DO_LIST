# Syntecxhub TO DO LIST

A simple and efficient productivity app for managing daily tasks.

## Overview
This to-do list application helps users add, update, delete, and complete tasks in a clean and user-friendly interface. Tasks are stored locally in the browser for convenience.

## Features
- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as complete
- Local storage persistence
- Responsive layout

## Tech Stack
- HTML5
- CSS3
- JavaScript

## Project Structure
```bash
Syntecxhub_TO_DO_LIST/
├── index.html
├── styles.css
├── script.js
├── README.md
└── assets/
```

## Getting Started
1. Clone the repository
2. Open `index.html` in your browser
3. Start creating and managing tasks

## Usage
- Add a task in the input field
- Mark it complete when finished
- Edit or delete tasks when needed
- Your tasks remain saved in the browser
