# Syntecxhub TO DO LIST

A simple and efficient To-Do List application that helps you stay organized and productive. With a user-friendly interface, you can easily add, update, delete, and mark tasks as complete to track your daily, weekly, and monthly activities.

## ✨ Features

- ✅ **Add Tasks** - Create new tasks with ease
- 🗑️ **Delete Tasks** - Remove completed or unnecessary tasks
- ✏️ **Edit Tasks** - Update task descriptions
- ✔️ **Mark Complete** - Check off tasks as you complete them
- 💾 **Local Storage** - Tasks persist even after closing the browser
- 📱 **Responsive Design** - Works on desktop, tablet, and mobile devices
- 🎨 **Clean UI** - Intuitive and user-friendly interface

## 🛠️ Technologies Used

- **HTML5** - Semantic markup and structure
- **CSS3** - Modern styling and responsive design
- **JavaScript** - Task management logic and interactivity

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/shanvichaudhary39/Syntecxhub_TO_DO_LIST.git
```

2. Navigate to the project directory:
```bash
cd Syntecxhub_TO_DO_LIST
```

3. Open `index.html` in your browser

## 📖 How to Use

1. **Add a Task:**
   - Type your task in the input field
   - Click the "Add" button or press Enter

2. **Mark Task Complete:**
   - Click the checkbox next to the task
   - Task will be marked as completed

3. **Edit a Task:**
   - Click the edit icon to modify the task
   - Update the task and save changes

4. **Delete a Task:**
   - Click the delete icon (trash bin)
   - Task will be removed from the list
